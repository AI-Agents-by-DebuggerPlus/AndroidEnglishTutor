# AET: что делать, если код Telegram не приходит

AndroidEnglishTutor (AET) входит в Telegram **как пользователь** (TDLib), как AHCC. Код нужен один раз, пока **локальная TDLib-сессия AET** на телефоне не сброшена.

См. также общую схему подключения к Hermes: [AET-Hermes-Telegram.md](./AET-Hermes-Telegram.md).

### Какую «сессию» сбрасывать

| Сессия | Где | Сброс в AET |
|--------|-----|-------------|
| **TDLib AET** | `files/tdlib-aet/` на телефоне | Кнопка «Сбросить сеанс» в миничате |
| TDLib AHCC / Desktop | Другие приложения | **Не** сбрасывается из AET |
| Hermes (контекст агента) | Сервер | Не то же самое, что логин Telegram |

«Сбросить сеанс» в AET = только логин Telegram **внутри EnglishTutor**.

## Важно

1. Код **почти никогда не SMS**.
2. Он приходит в **уже открытый Telegram** — служебный чат **«Telegram»** (не бот Hermes / не @GoraAcademyFirstBot).
3. Часто код видно на **Desktop Telegram** или на другом телефоне, где этот же аккаунт уже вошёл.
4. Повторная отправка часто **невозможна** (`Authentication code can't be resend`), пока не начнёте вход заново.

## Пошагово

### 1. Проверьте правильное место

- Откройте официальное приложение **Telegram** (или Telegram Desktop) на аккаунте с номером из настроек AET (`telegramPhone`, обычно `+1…`).
- Найдите чат **«Telegram»** (служебные уведомления о входе).
- Ищите сообщение вида **Login code: XXXXX**.
- Не ищите код в чате с ботом Hermes.

### 2. Подождите и не спамьте «Выслать ещё раз»

- После «Отправить телефон» подождите 1–2 минуты.
- Кнопка повторной отправки часто даёт ошибку — это нормально, если код уже был выслан.
- Если на экране AET уже **NeedCode** / поле для кода — код, скорее всего, уже ушёл в чат «Telegram».

### 3. Сбросьте TDLib-сеанс AET и запросите код снова

В миничате EnglishTutor (это **не** New session на AHCC Desktop):

1. **Сбросить сеанс** — очищается только `tdlib-aet` (или **Сброс → вход по QR**).
2. Снова **Отправить телефон** (или войдите по QR и подтвердите в открытом Telegram).
3. Снова откройте чат **«Telegram»** на Desktop / телефоне — должен прийти **новый** код.
4. Введите код в AET.

Если после кода спросят **2FA** — введите облачный пароль Telegram.

### 4. Если код всё равно не виден

- Убедитесь, что номер в AET совпадает с аккаунтом, где смотрите чат «Telegram».
- Проверьте **все** устройства с этим аккаунтом (телефон, Desktop, другой клиент).
- В Telegram Desktop откройте поиск → «Telegram» → служебный чат.
- Не запускайте одновременно несколько свежих логинов (AET + повторный сброс подряд) — возможна ошибка `Another authorization query has started`. Подождите и сделайте **один** сброс.

### 5. После успешного входа

1. Индикатор: **Telegram Ready** (оранжевый).
2. Нажмите **«Тест english_tutor (Telegram → Hermes)»**.
3. Зелёный **english_tutor подключён** — реальный ответ профиля через Hermes.
4. Только после этого генерируйте темы / пишите в миничат.

## Краткий чеклист

| Симптом | Действие |
|--------|----------|
| Ждёте SMS | Смотрите чат «Telegram» в приложении / Desktop |
| AET просит код, а в боте пусто | Код не в боте — в служебном чате «Telegram» |
| «Can't be resend» | Не жмите resend; сброс сеанса → новый код |
| Код был раньше, сейчас нет | Сброс сеанса AET → новый запрос |
| Вошли, но english_tutor «не проверен» | Кнопка **Тест english_tutor** |

## Технический фон (для отладки)

- AET: TDLib, каталог сессии `files/tdlib-aet/`.
- Тип доставки кода часто `AuthenticationCodeTypeTelegramMessage` (в логе: `WaitCode via=в уже открытый Telegram…`).
- Тег logcat: `AET-TG-User`.
- Inference в AET для агента **отключён**; без Telegram Ready миничат к Hermes не ходит.
